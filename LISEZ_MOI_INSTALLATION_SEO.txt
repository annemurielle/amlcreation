INSTALLATION SIMPLE, SITE AML CREATION
=====================================

Ce ZIP contient le site www.amlcreation.ch COMPLET, avec les corrections.
Il ne s'agit pas d'un simple outil d'analyse.

1. Décompresse le ZIP sur ton Mac.
2. Ouvre le dossier LOCAL de ton dépôt GitHub du site AML Creation.
3. Remplace les anciens fichiers du site par le CONTENU de ce ZIP.
   IMPORTANT : garde le dossier caché .git de ton dépôt local (ne le supprime
   pas). Le ZIP contient bien le dossier .github avec les workflows.
   Sur Mac, Cmd + Maj + . permet d'afficher les fichiers cachés dans Finder.
4. Enregistre les changements et fais Push sur GitHub comme d'habitude.
5. Le workflow GitHub Pages publie le site automatiquement et refait son
   contrôle SEO hors ligne. Dans GitHub Actions, vérifie que la publication
   est verte et que la ligne « SEO AUDIT PASSED » s'affiche.

Les fichiers accentués corrompus de l'ancien dossier doivent être retirés lors
 du remplacement intégral. Les nouveaux fichiers correctement nommés sont :
  Police-de-confidentialité.html
  Datenschutzerklärung.html

Ensuite, dans Google Search Console :
 - Ajouter/vérifier le sitemap https://www.amlcreation.ch/sitemap.xml
 - Inspecter les URL signalées par Google puis lancer « Valider la correction »
   lorsque les pages mises à jour sont accessibles.

Aucune date de publication, aucun prix, aucun avis et aucune note n'ont été
inventés. Le travail de Google (exploration, indexation, résultats enrichis)
se produit après la publication, sans garantie que toutes les pages figurent
immédiatement dans l'index.
