AML Creation, accueil multilingue (8 langues)

LANGUES : anglais /, français /fr/, allemand /de/, espagnol /es/, italien /it/, portugais /pt/, russe /ru/, japonais /ja/.

CONSERVÉ : URL de l'accueil anglais, toutes les URL confidentialité/support existantes, liens des boutiques, design et noms de vidéos.

AJOUTÉ : vrai texte traduit par page, sélecteur de langue accessible, canonical propre à chaque page, hreflang réciproques et x-default, sitemap-pages.xml, liens locaux aux jeux traduits quand existants.

AUTOMATISATION : le fichier tools/update_home_sonocalming.py actualise aussi les 7 nouveaux accueils à partir de SonoCalming/latest-videos.json. La GitHub Action quotidienne ajoute ces pages à ses commits.

INSTALLATION dans la racine amlcreation :
  ditto -x -k "$HOME/Downloads/AML_Creation_Accueil_Multilingue_SEO_2026-11-19.zip" .
  python3 tools/update_home_sonocalming.py
  git diff --check
  git status --short

TEST LOCAL :
  python3 -m http.server 8000
  http://localhost:8000/ et http://localhost:8000/fr/
  (Ctrl+C pour arrêter.)

Aucune redirection automatique selon la langue, pour laisser le choix au visiteur et faciliter l'indexation.

L'anglais est conservé pour les titres des vidéos YouTube et les pages des projets qui n'ont pas de traduction réelle.
La version française mène à la page française existante Games/jeux-IOS-android.html. Les pages de projets sans traduction disponible conservent un lien vers leur version anglaise.

PRÉCAUTION : le ZIP fusionne les fichiers, sans supprimer les dossiers existants. Ne pas ajouter les sauvegardes personnelles avec git add .
