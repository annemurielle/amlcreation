  Aide de Tiny Story 1 


Astuce: Si vous maintenez votre doigt pendant plus d'une seconde sur l'écran, vous verrez les endroits où il y a un objet ou une action à faire.

au cas où le jeu deviendrait un peu trop casse-tête pour vous.  Si vous ne trouvez pas la réponse à votre question, vous pouvez nous l'envoyer à l'adresse amlcreation.adventuregames@gmail.com, nous y répondrons aussi rapidement que possible.

Vous trouverez une aide détaillée directement dans le jeu. Cliquez sur le Q (Quest) et après sur l'icône Aide détaillée (Point d’interrogation vert). Chaque scène à sa propre aide, alors n'hésitez pas à l'utiliser.

Vous trouverez ci-dessous l'ancienne aide de Tiny Story 1. 

Cliquez sur la question pour afficher la réponse.

 Je n'arrive pas à accéder au grenier. Que faire?
 Le mechanisms à l'intérieur de l'horloge est la solution. Pour ouvrir l'horloge il faut utiliser les deux boutons situés sur la cuisinière. Le code à mettre est caché quelque part.

 Je n'arrive pas à ouvrir la porte pour accéder au toit. Que faire?
 Le code pour ouvrir le toit est caché dans le tiroir de la table de chevet. Vous devrez distraire le fermier de manière à ce qu'il fasse tomber la clé qui est dans sa poche et qui ouvrira la table de chevet.

 Je ne trouve pas le champignon violet. Où est-il?
 Observez bien l'extérieur de la maison du fermier.

 Je me suis trompé dans la création de la potion magique. Que faire?
 La potion brune ratée doit être utilisée sur la sorcière. La fiole vide pourra à nouveau être utilisée pour concocter une nouvelle potion. Les ingrédients utilisés réapparaissent aux endroits où vous les avez trouvés.

 Je suis bloqué dans le cimetière.
 Avez-vous de quoi creuser?

  Je ne trouve pas comment avancer dans le tunnel.
 Vous ne pouvez pas avancer dans le noir. Trouvez de quoi allumer les torches qui sont dans le tunnel. Cherchez chez le fermier.

 Je ne trouve pas le deuxième œuf.
 Un petit œuf dans le poulailler et un grand sur le toit..

 Le chien ne me laisse pas passer.
 Trouvez-lui un os à ronger.

  C'est quoi cet affreux drapeau avec le roi Rhino?
 Détruisez-le, c'est le symbole des Rhino qui ont envahi la ville. N'oubliez pas de ramasser le bâton. Il sera peut-être utile... à lancer...

 Que faire dans le bar?
 Allez à gauche de la porte. Quoi? Il y a un deuxième étage? ... Faites un feu de cheminée pour trouver des indices...

 Que faire dans la boulangerie?
 Miam, n'oubliez aucune friandise, tout est utile!

 Que faire dans la maison?
 De nombreux objets à ramasser. Ne les loupez pas !b... N'oubliez pas de noter les codes dévoilés par les lumières...

 Je ne peux pas entrer dans le commissariat.
 Avez-vous noté tous les morceaux de codes (deux dans la maison, un dans le souterrain)

 Comment entrez dans le musée?
 Trouvez les deux étoiles.

  Que faire dans le cirque?
 Un chapeau magique sans son lapin, c'est pas bien malin... Avez-vous vu les leviers cachés qui actionnent le canon de différentes manières. Mais que mettre dans le canon? Un objet qui se trouve devant la boulangerie, peut-être?

  Mais... il n'y a pas d'escalier pour monter au dernier niveau du musée!
 Des objets sont à replacer pour trouver les codes des tiroirs... heu? Quel est le rapport? Vous verrez bien..

 Je ne peux pas ouvrir le deuxième tiroir du musée. Que puis-je faire?
 Vous avez une autre possibilité de marquer le code sur les panneaux. Vous devez cliquer une fois sur chaque levier qui sont près de l'escalier. Lorsque vous cliquez sur les leviers, les panneaux de bois où les codes sont affichés sont activés (Un levier correspond à un panneau). Après vous pouvez directement cliquer sur le panneau en bois pour changer le code. Si vous ne pouvez pas cliquer sur le panneau de bois, cela signifie que vous avez peut-être cliqué plus d'une fois sur le levier correspondant.

 Je ne comprends pas le symbole qui sont en haut des portes dans le tunnel. Où puis-je trouver un indice pour cela?
 Vous ne trouverez aucun indic dans le jeu pour ce code. Vous devez voir que les symboles sont des chiffres (avec leur miroir). Vous avez besoin d'additioner les deux nombres du haut et mettre le résultat ci-dessous. Ou si le résultat est affiché, vous devez calculer le nombre manquant ...

 Je ne comprends pas le code dans la dernière partie du tunnel ...
 Avez-vous écrit le code qui est affiché sur la télévision dans le poste de police? Mettez ce code comme suit: le chiffre 1 correspond à 1 clic, le chiffre 2 à 2 clics, etc.

 Je ne peux pas aller dans l'eau. J'ai besoin du bocal du poisson, non?
 Non, vous n'avez pas besoin du bocal du poisson vu au poste de police. Vous trouverez un scaphandre si vous affichez les bons symboles près de l'eau. Vérifiez le point précédent pour les détails sur le code.

 Que donner au poisson qui veut me manger?
 Ce poisson aime les bonbons! Mais vous ne pouvez pas les lui donner directement ... donc vous avez besoin d'attacher un des bonbons à quelque chose avant de le lui donner.

 Je ne trouve pas le bois pour construire mon bateau! Où pourrais-je le trouver?
 Avez-vous nourri le poisson? Ou a-t-il encore faim? Si vous lui avez déjà donné le sucre cane, peut-être pouvez-vous mettre le petit bonbon rond bleu quelque part sur un rocher ... et voir ce qui se passe ...

 Je ne peux pas utiliser le marteau pour construire mon bateau ... pourquoi?
 Vous devez mettre le marteau avec les clous avant de l'utiliser.

 Je ne peux pas utiliser le tournevis pour construire mon bateau .. pourquoi?
 Vous devez mettre le tournevis avec les visses avant de l'utiliser.

 Que puis-je donner aux oiseaux affamés?
 Prenez 3 pains dans la boulangerie ...

  J'ai construit mon bateau mais je ne peux pas m'en aller. Pourquoi?
 Vous avez besoin d'une carte pour partir. Nourrissez les oiseaux pour l'obtenir.

 Je suis bloqué ailleurs, que faire?
 Expliquez-nous où vous être bloqué par email à l'adresse suivante: tinystoryadv@gmail.com. Nous vous répondrons aussi rapidement que possible.

 Le jeu ne fonctionne pas.
 Expliquez-nous dans quel scene le jeu à planté. Avez-vous essayé de charger une partie que vous avez sauvegardé précédemment? Notre adresse: tinystoryadv@gmail.com. Nous vous répondrons aussi rapidement que possible.

 Le jeu n'est pas disponible dans mon language. Puis-je contribuer à la traduction du jeu ?
 Oui, vous pouvez. Le jeu est disponible en anglais et en français. Si vous désirez l'avoir dans votre langue, par exemple en Turques ou Espagnol, contactez-nous à l'addresse tinystoryadv@gmail.com et nous vous enverrons les textes à traduire (en anglais ou français, selon votre choix). Renvoyez-nous les textes traduits et ils seront ajoutés à la prochaine mise à jour du jeu. Votre nom ou pseudo sera mis dans les crédits de l'application.
