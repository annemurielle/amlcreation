Somnifox のサポートとヘルプ

このページでは、Somnifox をすぐに使い始めるための手順、購入を復元する方法、 サブスクリプションの管理方法、よくある問題の対処法を説明します。 それでも解決しない場合は、このページからサポート宛てにメールを送ることができます。

アプリをダウンロード サポートにメール プライバシーポリシー

お問い合わせの際は、使用中のデバイスの機種名と iOS または iPadOS のバージョンも記載していただけると、よりスムーズにサポートできます。

Somnifox は iPhone と iPad で、広告なし・アカウント登録なし・完全オフラインで動作します。

クイックスタート

  1. + ボタンをタップして、雨、波、森、暖炉、ホワイトノイズ／ブラウンノイズなどの音を追加します。
  2. 各バブルをドラッグして、音量（上下）と 左右のバランス（左右）を調整します。
  3. 再生ボタンをタップしてミックスを開始し、必要であればスリープタイマーをセットします。
  4. オプション: 音楽やポッドキャストと一緒に再生したい場合は、Somnifox の設定で Allow other apps’ audio をオンにしてください。

アプリ内の言語設定

  • Somnifox 内で Settings → Interface → Language を開きます。
  • お好みの言語を選ぶか、「Follow device language」を選択してデバイスの言語に合わせることもできます。
  • この設定は、アプリ内のメニューやラベル、メッセージに適用されます。

購入の復元

  1. Somnifox → Settings を開きます。
  2. Restore purchases をタップします。
  3. Premium を購入したときと同じ Apple ID でサインインしているか確認してください。

それでも Premium が有効にならない場合は、サポートにメールする際に次の情報を添えてください。

  • デバイスの機種名（例: iPhone 13、iPad Air 5）。
  • 現在の iOS / iPadOS のバージョン。
  • 購入したプランの種類（Monthly、Yearly、Lifetime）。

サブスクリプションの管理と解約

サブスクリプションの管理は Apple が行います。Somnifox のサブスクリプションは次のページから確認・変更・解約できます。

Apple のサブスクリプション管理ページ

  • 購入時と同じ Apple ID でサインインしてください。
  • 次回の更新を止めたい場合は、更新予定日の 24 時間以上前に解約する必要があります。

トラブルシューティング

音が出ない場合

  • デバイスの音量を上げ、サイレントスイッチ（マナーモード）がオンになっていないか確認してください。
  • ヘッドホンやスピーカーが正しく接続されているか確認します。
  • 音楽と一緒に再生している場合は、Somnifox の設定で Allow other apps’ audio がオンになっているか確認してください。

タイマーが予定より早く止まってしまう

  • Low Power Mode（低電力モード）がオンの場合は、一時的にオフにして試してみてください。
  • バッテリー残量が非常に少ないときは、Somnifox を前面に表示したままにすると改善することがあります。
  • 再生を止めてしまう可能性がある省電力設定や Focus モードをオフにしてください。

購入後も Premium が有効にならない

  • App Store の購入履歴で、支払いが完了しているか確認してください。
  • Somnifox の設定で Restore purchases をもう一度実行してみてください。
  • それでも改善しない場合は、Apple の領収書またはアプリ内購入画面のスクリーンショットを添付してサポートにメールしてください。

料金とプランについて

  • Somnifox は App Store から無料でダウンロードできます。
  • Premium は月額、年額、または Lifetime（一度きりの買い切り）として利用できます。
  • 支払いは購入時に Apple ID から請求されます。
  • App Store の設定から、いつでもプランの変更やサブスクリプションの解約が可能です。
  • サブスクリプションがなくてもアプリは利用できますが、保存できるアンビエンスの数や利用できるサウンド、テーマは制限されます。
